# CodeSense Frontend

Frontend application for CodeSense - a code repository analysis and chat platform.

## 🚀 Live Demo

**[View Live Demo](https://codesense-frontend.vercel.app/)**

> ⚠️ **Note:** The first time you open the application, it may take a moment to load due to limited resources. Please wait patiently for the application to initialize.

## 🛠️ Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## 📦 Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file:
```bash
cp .env.example .env
```

3. Update `.env` with your API base URL:
```
VITE_API_BASE_URL=https://your-api-url.com
```

4. Run development server:
```bash
npm run dev
```

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
